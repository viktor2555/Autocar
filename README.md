## 🎯 Sobre o Projeto

O **AutoCar** é um site desenvolvido para o segmento de locação de veículos de alto padrão. O layout foi planejado para transmitir sofisticação, contando com uma identidade visual imersiva, vídeos de fundo e uma vitrine dedicada para modelos exclusivos.

---

## 🚀 Funcionalidades

- **Background Dinâmico:** Utilização de vídeo em alta definição para um impacto visual imersivo.
- **Vitrine de Veículos de Luxo:** Exposição de marcas renomadas como Aston Martin, BMW, Mercedes-Benz, Porsche e Range Rover.
- **Seções Informativas e Contato:** Estrutura otimizada para conversão e atendimento ao cliente.
- **Totalmente Responsivo:** Adaptado perfeitamente para desktops, tablets e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Estilização avançada, Flexbox e Grid)
- **JavaScript** (Interatividade da interface)
